# 관리자 재정 현황 로컬 미리보기

모든 화면은 합성 이름·합성 금액·합성 문서로 만든 로컬 브라우저 결과다. 실제 구성원 이름, 거래 금액, 계좌, 원본 경로는 이미지와 정적 코드에 포함하지 않았다.

변경 전에는 관리자실에 독립된 재정 현황 화면이 없었기 때문에 대응하는 `before` 화면은 없다. 아래 네 장이 새 화면의 팀/개인·데스크톱/모바일 기준 결과다.

- `desktop-team.png`: 데스크톱 팀 전체·진행 중 월
- `mobile-team.png`: 360px 팀 전체·진행 중 월
- `desktop-member.png`: 데스크톱 개인·확정 월
- `mobile-member.png`: 360px 개인·확정 월

## 근거가 있는 우선 개선점

1. **P0 · 손익·잔액 오인 방지** — 회사 월 수입·지출은 중복 제거가 끝나지 않았고, 팀 계좌 잔액은 은행 원증빙이 부족하다. `0원`이나 수입-지출 역산값 대신 `집계 보류/확인 필요`를 표시한다.
2. **P0 · 정산과 지급 상태 분리** — 계산 문서 확정은 실제 지급 완료가 아니다. 기간 상태·정산 카드·지급 예정 카드와 상세 설명에서 두 상태를 분리한다.
3. **P0 · 비공개 데이터 경계** — 실제 재정 JSON은 공개 저장소나 정적 번들에 넣지 않는다. 기존 정산 문서 관리자 경계와 private snapshot RPC만 사용한다.
4. **P1 · 의사결정 가능한 값 우선** — 미확인 회사 손익 카드로 첫 화면을 채우지 않고, 정산 잔액·보관 중인 팀 돈·지급 예정·개인 몫을 먼저 배치한다.
5. **P1 · 원천 의미 보존** — MoneyPin 은행행 합계는 별도 참고 상자로 분리하고 회사 수입·지출·현재 잔액으로 이름을 바꾸지 않는다.
6. **P1 · 숫자 근거 추적** — 모든 카드가 계산식·거래 근거·관련 확정 정산 문서 상세로 이어진다. 문서는 기존 접근 감사 뒤 60초 서명 링크로만 연다.
7. **P1 · 실패와 만료 처리** — 조회 실패 시 이전 숫자를 현재값처럼 남기지 않고 재시도를 제공한다. 세션 만료 시 재정 모델과 상세 패널을 비운다.
8. **P2 · 좁은 화면·키보드 동선** — 360px에서 가로 넘침 없이 범위·월 선택과 1열 카드를 제공하며, 카드 상세는 Escape·브라우저 뒤로가기·초점 복귀를 지원한다.

## 읽기 전용 검증 근거

- 전달 원천 15개 SHA-256 재확인
- 최종 전달 묶음 11개: PDF 8, XLSX 2, TXT 1, ZIP CRC 정상, 중복 0
- 최종 정산·개인통장 XLSX 수식 29개·23개, 계산 오류 0
- MoneyPin 월별본 데이터 행 255개·200개, 10열, 수식·오류 셀 0
- 원본 파일 변경 0
