# royalty-read — 인세시트 읽기 전용

서류실 「작가 정산」 탭이 통합 인세시트의 작가·도서·판매·재고 기록을 자동으로 불러올 때 쓴다. 시트에 쓰지 않는다.

- 인증: `scm-read`와 같다. `verify_jwt: true`로 배포하고, 요청마다 로그인 사용자 → `is_admin()` → `admin_emails` 순서로 확인한다.
- 구글 인증: `scm-read`와 같은 비밀값 `SCM_GOOGLE_SERVICE_ACCOUNT`(읽기 전용 범위)를 쓴다. 인세시트가 그 서비스 계정에 공유되어 있어야 한다. 공유가 안 되어 있으면 `SHEET_NOT_SHARED`와 함께 서비스 계정 이메일을 관리자에게만 돌려준다.
- 시트 ID: 공개 저장소에 두지 않는다. `public.doc_settings`의 `royalty_sheet_id`, `scm_sheet_id`를 요청한 관리자의 권한으로 읽는다.
- 캐시: 55초. 읽기가 실패하면 10분 안의 마지막 성공 결과를 `stale: true`로 돌려준다.
- 읽는 탭: `기준정보`, `위탁재고`, `작가정산`, `인세 원장(DB)`, `대시보드`.
- 돌려주는 값: 기존 호환용 `header`, `rows`, `exemptUsed`, `nonSaleRows`, `dashboard`와 함께 `books`를 돌려준다. `books`에는 기준정보에 등록된 작가·도서별 정산 유형, 정가, 작가율, 판매 기록, 입고·샘플·현재고 현황이 들어간다.
- 자체출판 저자 인세는 상세 인세 원장을, 외부위탁은 위탁재고의 `판매` 행만 매출로 사용한다. 결제완료·미출고처럼 판매/유출이 0인 행과 별도 샘플은 매출에 섞지 않는다.
- 《문고리》의 납본·책방/증정 샘플·서평단 배포와 면제 누계는 SCM `현황` 탭을 실시간 우선값으로 사용한다. 따라서 5+1 책방 발송의 샘플 1권은 판매·인세가 아니라 운영 현황과 인세 면제 부수에만 반영된다.
